# Документация проекта

> Статус: **active**. Индекс документов. Обязательный краткий контракт — в
> `AGENTS.md`, подробные правила — в самих документах.

## Порядок чтения

1. `AGENTS.md` — команды, инварианты и карта «что читать под задачу».
2. Этот файл — выбрать актуальный документ по теме.
3. Соответствующий план или checklist темы.
4. Исходники, конфигурация и тесты рядом с изменяемым кодом.

## Правила

- У каждой темы ровно один владелец: остальные документы ссылаются на него, а не
  пересказывают. Новый документ создаётся, только если темы нет в существующем.
- У документа есть статус (`draft`, `active`, `completed`, `archived`) и
  понятная область применения. Ссылки на конкретный файл или команду проверяются
  при изменении источника истины.
- Подробные материалы живут в `docs/`, а не в корне. Не создавать отдельные
  `docs/commands.md` или `docs/known-issues.md`: команды принадлежат
  `quality-gates`, известные проблемы — backlog и checklist. `README.md` в корне
  остаётся кратким обзором продукта, а не вторым руководством агента.
- `docs/backlog.md` содержит только открытые задачи: выполненные удаляются, а
  критичные для проекта факты из них переносятся в тематический документ.
- `docs/archive/` — временная историческая справка, не источник критериев
  приёмки; срок хранения 30 дней, файлы восстановимы из git history.
  Единственный документ в архиве со статусом `active` —
  `docs/archive/README.md`: он описывает процедуру архивирования, а не архивный
  материал, поэтому не подлежит 30-дневному удалению.
- Ссылаясь на инструмент по id, сверять id с реестром (`web/src/lib/registry/`):
  исторические названия в старых планах не действуют. Сейчас `id` записи — это
  одновременно адрес страницы `/tools/<id>`, отдельного поля `slug` нет
  (`docs/architecture.md`, раздел 3).
- Поиск по `docs/` задевает `docs/archive/` (объём больше, чем у активных
  документов вместе). Для правок production-кода архив не нужен: grep по
  `docs/*.md` без `archive/`.
- Проверка ссылок в документации не автоматизирована; ожидаемо неразрешимыми
  считаются ссылки на `docs/plan-domain.local.md` (файл вне git). Всё остальное
  неразрешимое — ошибка.
- Протокол «остановиться и показать изменения» — `docs/agent-workflow.md`,
  раздел 6.
